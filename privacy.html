Privacy Policy

Last updated: September 2026

The short version: AgentLog Share doesn't have a server. Files you open are read and processed entirely inside your own browser. We never receive, see, or store your session data, and we don't run any tracking or analytics on this site.

What this app does with your files

When you drop in a .zip or .jsonl file, all parsing happens locally using JavaScript running in your browser. The file is never uploaded, transmitted, or sent to any server — ours or anyone else's. We have no way to see the contents of files you process, because they never leave your device.

What's stored, and where

  • Profile name: the name you enter is saved in your browser's localStorage, on your device only.
  • Session history: parsed conversations you've opened are saved in your browser's IndexedDB, also on your device only, so you can reopen them later without re-uploading.

None of this is synced to a server, accessible to us, or shared with anyone. Clearing your browser's site data (or using a different browser or device) removes it permanently — we cannot recover it for you, because we never had it.

Automatic redaction

Before displaying content, the app scans for patterns that look like API keys, tokens, or passwords and masks them. This is a best-effort pattern match, not a guarantee — please don't rely on it as your only safeguard if your session data contains real secrets, and treat exported files with the same care as the original.

Third-party resources this page loads

To read .zip files, this page loads a small code library (JSZip) from a public content delivery network (cdnjs, operated by Cloudflare). Loading any resource from the internet involves a standard web request, which may let that third party see basic technical information such as your IP address — the same as visiting any website. We don't control this and it's unrelated to the contents of your session files, which are never part of that request.

Hosting

This site is hosted as a static site (e.g. via Netlify or a similar provider). Like any website host, the hosting provider may log standard access information (such as IP address, browser type, and request timing) for infrastructure and security purposes. This is standard web hosting behavior, separate from and unrelated to your session data.

Cookies and tracking

This site does not use cookies and does not run any analytics or tracking scripts at this time. If that changes, this policy will be updated to reflect it before any such feature ships.

Children's privacy

This app is not directed at children and doesn't knowingly collect any data from anyone, of any age — because it doesn't collect data at all.

Changes to this policy

If this policy changes, we'll update this page and the "last updated" date above.

Contact

Questions about this policy can be raised via the project's GitHub issues page.
